Hi, I'm **Ravi Shankar** — an indie developer based in Chennai, India. I build apps for Apple platforms, and I build the AI tools that help other developers ship them faster.

I've shipped 10 apps across iPhone, iPad, Mac, and Apple Watch, and I share open-source Claude Code tools for other developers. I've also been writing here about iOS and Swift since 2008 — mostly figuring things out in the open. Two sides of the same coin: I like making things, and I like sharing what I learn along the way.

## What I build

### Apps for Apple platforms

I focus on apps that solve practical problems — usually ones I have myself. A few I'm proud of:

* **[Magizh](/magizh)** — a mindfulness companion for iPhone and Apple Watch
* **[Expense Split](/expense-split/)** — split and settle shared expenses
* **[ChantFlow](/chantflow/)** — a mantra-counting companion for Apple Watch

See the [full portfolio →](/portfolio/)

### AI tools for Apple developers

I'm fascinated by AI-assisted development, so I build the tooling that makes it work for real Apple projects:

* **[claude-code-apple-skills](https://github.com/rshankras/claude-code-apple-skills)** — 139 Claude Code skills for Apple platform development
* **[SwiftShip](https://github.com/rshankras/SwiftShip)** — spec-driven iOS/macOS development for Claude Code
* **[indie-app-autopilot](https://github.com/rshankras/indie-app-autopilot)** — an AI pipeline from GitHub issue to App Store
* **[asc-metadata-mcp](https://github.com/rshankras/asc-metadata-mcp)** — App Store Connect, controlled from Claude Code

Everything's on [GitHub →](https://github.com/rshankras)
